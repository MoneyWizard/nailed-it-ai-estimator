# Nailed It AI Deck Estimator
**30-Day Tool Factory • Day 1**

Instant, AI-powered deck cost estimator for home improvement / deck contractors.

## Features
- Lead capture (name, email, phone)
- Smart material & labor calculations with waste factors
- Regional pricing multipliers
- Material breakdown table
- Printable / copyable quotes
- Pure HTML/CSS/JS — zero dependencies, deploys anywhere

## Revenue Use
- Embed on website as lead magnet
- Generate instant ballpark quotes → book site visits
- Collect emails for nurture sequences (Day 8 tool)

## Deploy
1. Upload `index.html` to any static host (Vercel, Netlify, GitHub Pages)
2. Or open directly in browser
